# CodeTantra Code Helper

**Your Smart Coding Companion for CodeTantra Practice.**

A lightweight Chrome extension designed to improve the coding experience on supported CodeTantra practice editors.

## Features

- Chrome Extension built with Manifest V3.
- Helper functionality for supported CodeTantra editors.
- Lightweight browser-side implementation.
- Simple installation using Chrome Developer Mode.

## Installation

1. Download the project ZIP from GitHub.
2. Extract the ZIP file.
3. Open Chrome and visit `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.
7. Open a supported CodeTantra practice page.

## Compatibility

The extension currently supports selected CodeTantra editors. Some pages may use unsupported editor implementations.

## Troubleshooting

If you see "No supported visible editor was detected":

- Refresh the practice page.
- Check that the extension is enabled.
- Verify that the editor is supported.
